## [1.2.0] — 2026-11-14（versionCode 3）

### 性能
- **转换内核提速**：PNG 编码关闭 `optimize=True`（第二遍最优霍夫曼搜索在 ARM 上极慢），
  默认压缩级 6；实测对编码环节提速约 10~15%（ARM 上更明显），产物体积仅略增。
- **新增"极速档"（性能模式升级）**：在原有 `max_size=256` 基础上，叠加
  `fast_encode`（编码压缩级降至 4 + 重采样由 LANCZOS 降级为 BILINEAR）。
  强制重采样场景下整组转换再快约 16%，且产物更小（测试 249.7KB → 238.7KB）。
- **多线程并行保留并增强**：S5 阶段仍用线程池（numpy 主动释放 GIL，真并行吃多核）。
  实测 200 组 512px 包：单线程 18.1s → 4 线程 5.2s（3.5×）→ 8 线程 4.3×。
  UI 新增**线程档位（自动 / 4 / 8）**，避免旧机 8 线程抢占反变慢。
- **并行感知 ETA（墙钟速率）**：剩余时间按"已完成组数 / S5 墙钟耗时"估算，天然兼容
  多核，不再因核心数多而高估。

### UI（重做，仍纯原生、离线）
- 新增**预设选择**（标准 / 高度图 / 精细 / 快速 / 自定义），从 Python 侧 `presets()` 拉取。
- 新增**选项区**：兼容模式、性能模式、线程档位、贴图上限档位（512/1024/2048）。
- 新增**进度可取消**：转换中显示"取消转换"按钮。
- 新增**结果页**：12/12 校验通过提示、产物名与大小、**原图/色彩/法线/MER 预览缩略图**
  （此前 Python 已算好但从未展示）、导入与历史入口。
- 新增**转换历史面板**：读取本地 SQLite 历史（最近 50 条）。

### 版本管理
- 引入 git 仓库、`.gitignore`、`VERSION.md`、`CHANGELOG.md`。
- `versionCode` 1→3，`versionName` 1.1.0→**1.2.0**（注：1.1.0 为已发布未入库版本）。
