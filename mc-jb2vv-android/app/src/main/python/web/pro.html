      S1 读取归档 S2 解析元数据 S3 类型预检 S4 标识符映射 S5 通道转换 S6 动画迁移 S7 生成 JSON S8 校验打包

      LabPBR → Vibrant Visuals 通道映射

      • roughness = (1 − smoothness)²（禁止 255−R 近似）
      • metalness：_s.G ≥ 230 判为金属，≤ 229 为电介质
      • emissive = (255 − _s.A) / 254
      • normal Z = √(1 − X² − Y²)，平面基准 (128,128,255)
      • heightmap ← _n.A 单通道；AO ← _n.B（可选烘焙）
      • LabPBR 与 Bedrock 同为 DirectX Y-，默认不翻转

      官方硬约束（导出前校验）

      • normal 与 heightmap 不可同时定义
      • MER 与 MERS 不可同时定义
      • heightmap 禁用于 items / entity / particle
      • color 为唯一必选层；引用须同包无扩展名短名
      • capabilities 仅 ["pbr"]，禁止 raytracing
      • min_engine_version ≥ [1, 21, 120]
