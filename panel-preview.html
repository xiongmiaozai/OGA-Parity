v1.4.6 资源库分类增强

  • 分类与排列工具条：三种分组维度——按时间（今天 / 昨天 / 日期）、按类型（Java / 基岩版）、按批次（一次转换的输入+产物归组，Java 在前、基岩版在后）。
  • 排序方向（最新在前 / 最早在前）与类型过滤（全部 / 仅 Java / 仅基岩版），三者可自由组合。
  • 包图标：每条记录左侧显示图标，优先读取包内 pack_icon.png（基岩）/ pack.png（Java）；缺失时回退到彩色字母徽标（J=Java 绿 / B=基岩蓝），带内存缓存。
  • 批次号 batchId：同一次转换的导入包与导出产物共享；「查看」弹窗显示批次号，旧记录显示「旧记录」兼容。删除记录时清理图标缓存。
  • 「查看 / 下载(SAF) / 删除」按钮保留在卡片底部整行，不与图标/文字重叠；全程离线、无 INTERNET、仅 arm64-v8a。
